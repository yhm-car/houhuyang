# LogicSim · 逻辑关系图

一个**完全离线**的逻辑表达式图形编辑器：输入逆波兰表达式，自动生成可编辑、可导出的逻辑关系图。

- 在线使用：<https://houhuyang.github.io/houhuyang/>
- 纯静态站点，无构建步骤、无后端；所有解析与计算都在浏览器本地完成，可断网使用。

## 打开与使用

克隆或下载本仓库后，用 Edge / Chrome 打开根目录的 `index.html` 即可，**无需安装依赖、无需联网**。

1. 在「逆波兰表达式」框输入表达式，例如 `a b . fe >`，也可以直接点右侧的示例按钮。
2. 点击「生成逻辑图」，或按 <kbd>Ctrl</kbd> / <kbd>⌘</kbd> + <kbd>Enter</kbd>。
3. 拖动节点调整位置；拖动空白处平移画布；滚轮或 `+` / `−` 按钮缩放；`0` 适应画布。
4. 点击节点后在右侧编辑「名称」和「备注」，点击「保存修改」。节点类型不能通过名称字段改变。
5. 点击「保存文件」导出当前图形；点击「载入文件」载入 `.json` / `.txt` 模型。

展开「查看 / 编辑 JSON 模型」可使用「仅解析」「文本转图」「图转文本」。保存文件始终导出当前图形；若只编辑了 JSON，请先点「文本转图」应用修改。

可从输出端口拖到输入端口手动添加连线；重复输入和循环连接会被拒绝。鼠标悬停连线显示删除按钮。删除节点会同时删除相关连线。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| <kbd>Ctrl</kbd> / <kbd>⌘</kbd> + <kbd>Enter</kbd> | 生成逻辑图 |
| <kbd>+</kbd> / <kbd>−</kbd> / 滚轮 | 缩放 |
| <kbd>0</kbd> 或双击空白处 | 适应画布 |
| <kbd>L</kbd> | 重新布局 |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | 删除选中节点 |
| <kbd>Esc</kbd> | 取消选中 |

## 表达式规则

| 运算 | 输入 |
| --- | --- |
| 与 ∧ | `a b .` |
| 或 ∨ | `a b ,` |
| 非 ¬ | `a <` |
| 推出 → | `a b >` |
| 等价 ↔ | `a b =` |

变量和运算符之间必须用空白分隔。支持中文变量名、单个变量和常量 `0` / `1`。重复分支、恒真和恒假表达式会自动简化，因此图形可能与原版不同。

## 界面特性

- 深色 / 浅色主题：默认跟随系统，右上角按钮可手动切换，选择会记在 `localStorage`。
- 画布总览（小地图）带**可视区域指示框**，缩放和平移时实时更新。
- 语义化标签、跳转链接、`aria-label`、`:focus-visible` 焦点环，键盘可完成主要操作。
- 响应式布局：宽屏左右分栏，窄屏（≤800px）自动纵向排布，无横向溢出。
- 状态栏 `aria-live` 播报操作结果与错误，错误状态有独立配色。

链接参数（便于分享特定状态）：

| 参数 | 作用 |
| --- | --- |
| `?theme=light` / `?theme=dark` | 强制浅色 / 深色主题，忽略系统偏好 |
| `?demo=1` | 打开页面后立即渲染示例表达式 `a b . fe >` |
| `?demo=1&theme=dark` | 组合使用，例如 <https://houhuyang.github.io/houhuyang/?demo=1&theme=dark> |

网格与画布底色完全由 CSS 变量（`--grid` / `--canvas`）驱动，切换主题不需要脚本重绘。

```sh
npm test
```

## 实现要点与限制

- 使用**有序二元决策图**：以变量首次出现顺序为序，合并相同分支、缓存相同运算，只绘制最终结果可达的选择节点。
- 为限制复杂输入，当前支持最多 512 个词元、64 个变量；计算中最多 4096 个决策节点、50000 次未缓存运算；载入最多 2000 个节点、6000 条连线，文件不超过 2 MB。不同变量顺序可能生成不同大小的图。
- 决策图仍可能随变量数指数增长，因此没有宣称已解决所有大图性能问题。
- 旧版 `nodeArray` / `linkArray` 模型仍可载入。数字编号会规范化为字符串；`memo`、`label`、`position` 字段用于备注、可选显示标签和位置保存。模型不允许重复编号、悬空连线、无效端口、同一端口多个输入和循环连接。
- 这是逻辑表达式图形编辑器，**不含**电路时序仿真，也不做逻辑正确性自动证明。
